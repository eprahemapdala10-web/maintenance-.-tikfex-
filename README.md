# 🛠️ تك فيكس - TechFix (صيانة سخانات وبوتجازات الجيزة)

تطبيق ويب متكامل وتفاعلي فائق السرعة لطلب صيانة منزلية فورية وشراء قطع غيار للبوتجازات وسخانات الغاز بالجيزة.

---

## 🚀 المميزات الرئيسية (Core Features)

1. **معالج الصيانة الفوري الذكي (Interactive Maintenance Wizard)**: خطوة بخطوة لتحديد المشكلة والجهاز
2. **متجر قطع غيار معتمد (Certified Spare Parts Store)**: سلة مشتريات تفاعلية
3. **تثمين الأجهزة المستعملة (Trade-In/Exchange)**: نموذج مريح لبيع الأجهزة القديمة
4. **تكامل تام مع WhatsApp & Phone**: إرسال الطلبات بصيغة منسقة
5. **لوحة تحكم إدارية محمية (Protected Admin Panel)**: تعديل قائمة قطع الغيار
6. **تحسين محركات البحث (SEO Optimized)**: Meta Tags كاملة وخريطة موقع

---

## 🎨 الهوية البصرية (Theme Aesthetic)

- **مساحات داكنة عميقة**: `bg-[#0c0c0e]` و `bg-[#111114]`
- **خطوط قوية عريضة**: `Cairo` و `Inter`
- **تفاعل حركي ناعم**: استخدام `motion/react` (Framer Motion)
- **أيقونات من Lucide React**: تصميم متجاوب بالكامل

## 📦 التثبيت والتشغيل المحلي (Setup & Installation)

### 1. قم بتحميل المشروع
```bash
git clone https://github.com/eprahemapdala10-web/maintenance-.-tikfex-.git
cd maintenance-.-tikfex-
```

### 2. تثبيت الحزم البرمجية
```bash
npm install
```

### 3. إعداد المتغيرات البيئية
```bash
cp .env.example .env
# قم بتحرير .env وإضافة GEMINI_API_KEY الخاص بك
```

### 4. التشغيل في بيئة التطوير
```bash
npm run dev
```
افتح المتصفح على `http://localhost:3000`

### 5. بناء النسخة النهائية
```bash
npm run build
```

### 6. اختبار النسخة الإنتاجية
```bash
npm run preview
```
