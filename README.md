# 🛠️ تك فيكس - TechFix (صيانة سخانات وبوتجازات الجيزة)

تطبيق ويب متكامل وتفاعلي فائق السرعة لطلب صيانة منزلية فورية وشراء قطع غيار للبوتجازات وسخانات الغاز بالجيزة ومناطق جنوبها (الحوامدية، البدرشين، وما يجاورها) بتصميم عصري جريء (Bold Typography).

---

## 🚀 المميزات الرئيسية (Core Features)

1. **معالج الصيانة الفوري الذكي (Interactive Maintenance Wizard)**: خطوة بخطوة وبلغة فصحى وعامية مبسطة ليتمكن العميل من تحديد العطل ونوع الجهاز (بوتجاز أو سخان غاز) وموقع سكنه.
2. **متجر قطع غيار معتمد (Certified Spare Parts Store)**: مع سلة مشتريات تفاعلية تمكن العميل من إضافة القطع والتعديل على الكمية وتحديد بيانات التوصيل المنزلي السريع.
3. **تثمين الأجهزة المستعملة والاستبدال (Trade-In / Exchange)**: نموذج مريح يُتيح للعميل استبدال أو تجديد جهازه القديم ومتابعته مباشرة.
4. **تكامل تام مع WhatsApp & Phone**: يتم إرسال كافة التفاصيل والطلبات بصيغة نصية منسقة مسبقاً لرقم الفني والمورد لضمان الاستجابة في ربع ساعة فقط.
5. **لوحة تحكم إدارية محمية (Protected Admin Control Panel)**: تمكن صاحب الورشة من الدخول برقم سري وتعديل قائمة قطع الغيار المتوفرة وتحديث بيانات التواصل والمحافظة على خصوصية البيانات.
6. **تحسين كامل لمحركات البحث (SEO Optimized)**: مجهز بـ Meta Tags كاملة، خريطة موقع `sitemap.xml` وملف الروبوتات `robots.txt` بالإضافة الى بيانات هيكلية منظمة من نوع `LocalBusiness (JSON-LD)` معتمدة لمنطقتك.

---

## 🎨 الهوية البصرية (Theme Aesthetic)

تم تصميم التطبيق وفق هوية **الخطوط العريضة والمساحات المتباينة (Bold Typography Theme)** ذات الطابع الصناعي الحديث:
- مساحات داكنة عميقة ومريحة للعين `bg-[#0c0c0e]` و `bg-[#111114]`.
- خطوط قوية عريضة ممثلة بـ `Cairo` و `Inter`.
- حواف حادة هندسية `rounded-none`.
- تفاعل حركي ناعم باستخدام `framer-motion (motion/react)`.
- فواصل وحدود بارزة وواضحة `border-white/10`.

## 📦 التثبيت والتشغيل المحلي (Setup & Installation)

للبدء بتشغيل المشروع على حاسوبك الشخصي:

1. **قم بتحميل المشروع أو عمل Clone**:
   ```bash
   git clone <رابط-مستودع-جيت-هاب>
   cd <اسم-المجلد>
   ```

2. **تثبيت الحزم البرمجية (Install Dependencies)**:
   ```bash
   npm install
   ```

3. **إعداد المتغيرات البيئية (Environment Variables)**:
   قم بإنشاء ملف باسم `.env` في المجلد الرئيسي وإدراج القيم المطلوبة كما في `.env.example`.

4. **التشغيل في بيئة التطوير المحلية (Start Dev Server)**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على العنوان التالي: `http://localhost:3000` لمشاهدة الموقع فورياً.

5. **بناء النسخة النهائية للإنتاج (Production Build)**:
   ```bash
   npm run build
   ```
   سيتم توليد الملفات الثابتة الجاهزة للرفع داخل مجلد `dist/`.
